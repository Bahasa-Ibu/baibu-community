# Community

Baibu Community Edition is developed in public. Anyone can report a bug,
propose a feature or send a pull request.

## Documents

- [Project charter](../project/charter.md): vision, scope, licence and
  trademarks.
- [Code of conduct](code-of-conduct.md): the standards we expect in all
  project spaces. Report concerns to
  [contact@baibu.id](mailto:contact@baibu.id).
- [Contributing guide](contributing.md): how to set up, test and send a
  change.
- [Security policy](security.md): how to report a vulnerability privately.
- [Handling conduct reports](conduct-reporting.md): how maintainers handle
  code of conduct reports.
- Governance: roles, decision-making and how to become a maintainer. Coming
  in Q3 ([#25](https://github.com/Bahasa-Ibu/baibu-community/issues/25)).

## Where to take part

- [Issues](https://github.com/Bahasa-Ibu/baibu-community/issues): bugs, feature requests and all planned work.
- [Milestones](https://github.com/Bahasa-Ibu/baibu-community/milestones): work grouped by quarter.
- [Pull requests](https://github.com/Bahasa-Ibu/baibu-community/pulls): changes under review.

Issues labelled
[`good first issue`](https://github.com/Bahasa-Ibu/baibu-community/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
are a good place to start.

A public discussion channel is planned for Q3
([#26](https://github.com/Bahasa-Ibu/baibu-community/issues/26)). Until then, use issues for questions.
