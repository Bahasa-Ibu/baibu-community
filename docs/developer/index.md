# Developer documentation

Architecture and configuration reference arrive with the application
skeleton.

This section will cover:

- an overview of the architecture: the Django apps, Celery tasks, storage and
  the adapter interfaces for third-party services;
- a configuration reference listing every environment variable;
- how to write an adapter for a model endpoint or another service.

Progress is tracked in
[issue #11](https://github.com/Bahasa-Ibu/baibu-community/issues/11).
Until then, see [Getting started](../getting-started.md) and the
[contributing guide](../community/contributing.md).
